## 0.4.27

### Changed

- 값이 들어간 입력칸만 글자를 가운데 맞춘다. 빈 칸의 정렬은 유지한다.
- 수식 입력기가 조판에 실패하면 "정답을 다시 입력해주세요."를 보여주고, 미리보기 스크롤이 입력 위치를 따라간다.
- 레이블이 없는 선다형은 정답 칸에 기호 대신 선택지 본문을 표시한다.

## 0.4.26

### Changed

- 진위형 버튼을 콘텐츠 너비로 가운데 정렬하고, 진술이 여러 개이면 발문과 버튼을 세로로 쌓는다.
- `qti-ext-display-type-ox`일 때 O/X를 아이콘으로 표시한다. 버튼 최소 크기는 120×60, 아이콘은 24px이다.

## 0.4.25

### Fixed

- mqti prod 기준으로 빈칸·단답 입력 상한을 50자로 올리고, 축소 미리보기의 이미지 빈칸 위치, 정오답 포커스 색, 끌어놓기 빈칸 들여쓰기를 맞췄다.

## 0.4.24

### Fixed

- practice에서 `responses`와 `onResponse`를 같이 쓸 때, 답 복원·부모 리렌더만으로
  `onResponse`가 반복 호출되던 오류를 수정했다. 사용자 입력이 답을 바꿀 때만 호출한다.
  (0.4.21에서 `useEffect`로 옮기며 생긴 회귀. 0.4.6 동작과 같다.)
- MathJax 수식 중첩 재조판으로 인한 브라우저 크래시(`STATUS_STACK_OVERFLOW`) 수정.
  - `MathJaxContext`에 `src`가 지정되지 않아 기본 번들 `tex-mml-chtml.js`(MathML 입력 처리기 포함)가
    로드되던 문제. `dynamic` 재조판 시 이전 출력의 `<mjx-assistive-mml>` 안 MathML을 새 입력으로
    재인식해 출력이 중첩되고, DOM 깊이가 선형 증가하다 Blink 렌더러 스택을 넘겨 탭이 크래시했다.
    (수업보드처럼 presence로 5초마다 리렌더되는 화면에서 약 1시간 후 발생)
  - 뷰어는 TeX 입력만 사용하므로 `src`를 `tex-chtml.js`(cdnjs 3.2.2)로 고정. MathML 입력만 빠지고
    기능 손실은 없으며, 스크린리더용 보조 MathML 출력(assistive-mml)은 그대로 유지된다.
  - 재발 방지: `MATHJAX_SRC` 상수를 검증하는 가드 단위 테스트(vitest)와 리렌더 반복 시 DOM 깊이가
    증가하지 않는지 확인하는 E2E 크래시 회귀 테스트(Playwright)를 추가.
- 수식 키보드가 `document.body`로 포탈될 때 호스트 화면 밖에 가려지던 문제를 수정했다.

### Changed

- 빈칸 채점(`ignoreAnswerOrder`), 선택형 정오답, 수식 키보드·이미지 빈칸을 mqti `dev` 기준으로 맞췄다.

### Note

- 내용이 바뀌지 않는 수식의 `dynamic` 비활성화(불필요 재조판 감소)는 사이징 회귀 리스크가 있어
  별도 작업으로 분리한다. 본 릴리스에는 포함하지 않는다.
