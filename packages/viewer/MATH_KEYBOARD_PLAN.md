# 수식 키보드

입력창과, 필요할 때만 뜨는 플로팅 키패드. 값은 **LaTeX 문자열**이다.

---

## 입력창

- 값 영역 + 우측 키보드 아이콘이 한 박스다.
- 아이콘은 입력창 오른쪽에 고정한다.
- 키패드가 열리면 MathLive로 작성하고, 닫히면 같은 값을 MathJax로 보여 준다.
- 열린 동안에만 선택(파란) 테두리를 준다.

**크기**
- 기본 최소 크기보다 작아지지 않는다.
- 입력하면 늘어나고, 지우면 줄어든다.
- 비우면 키패드를 닫지 않아도 기본 크기로 돌아간다.

---

## 열기 · 닫기

- **연다**: 우측 아이콘, 닫힌 값 영역 클릭, 또는 닫힌 입력창에서 숫자 등을 바로 입력.
- **닫는다**: 아이콘 다시 클릭, 또는 입력창·키패드 바깥 클릭.
- 포커스만으로는 열리지 않는다.
- 읽기 전용일 때는 값만 보여 주고, 아이콘·키패드는 없다.

---

## 플로팅 키패드

- 뷰포트에 고정하고, 핸들로 드래그한다.
- 화면 밖으로 나가지 않게 위치를 보정한다.
- 입력창 크기가 변해도 키패드 위치는 따라가지 않는다.

```
[ 수식 값                    ⌨️ ]
                 ┌ 핸들 ─────────┐
                 │ [서랍] │ 숫자패드 │
                 └────────────────┘
```

**우측 고정 패드 (5×5)**  
숫자·사칙·분수·루트·`x`/`y`·커서·지우기·엔터. 서랍 없이 쓸 수 있다.

**좌측 서랍**  
`>` / `<`로 열고 닫는다. 심화 기호용이다.

| 레벨 | 서랍 탭 |
| --- | --- |
| 중등 | 최근 사용, 기본, 대수, 기하 |
| 고등 | 위 + 집합·행렬, 통계 |

- 탭은 한 줄. 넘치면 가로 스크롤.
- 심화 키는 4열 격자, 세로는 스크롤.
- 넓은 키(행렬 등)는 한 행에 2개까지.

---

## 입력

수식 키패드와 디바이스 키보드는 같은 LaTeX로 들어간다.

- 숫자, `.` `+` `-` `=`, `*`(`\times`), `/`(`\div`), `x` `y`
- 백스페이스, 좌우 화살표
- 엔터는 현재 값을 제출한다

---

## 이력

브라우저를 닫아도 유지한다.

- 마지막 탭
- 최근 심화 기호(최대 12개). 우측 숫자·사칙·분수·루트·변수는 넣지 않는다.
- 서랍 열림 여부
- 키패드 위치

이력이 없으면 탭은 `기본`, 서랍은 닫힘.
