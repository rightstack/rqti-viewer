# 수식 키보드

학생이 답을 수식으로 쓰는 입력기다. 문항 흐름 안에 입력창이 있고, 키패드는 필요할 때만 뜨는 플로팅 팝업이다.  
입력·표시에 쓰는 값은 항상 **LaTeX 문자열**이다.

---

## 입력창

값과 키보드 아이콘을 한 박스로 둔다. 아이콘은 입력창 오른쪽에 붙어 있으며, 박스가 늘거나 줄어도 오른쪽 자리를 지킨다.

키패드가 열려 있을 때는 MathLive로 작성한다. 커서와 빈칸(플레이스홀더)이 그대로 보인다. 키패드를 닫으면 같은 LaTeX를 MathJax로 조판해 보여 준다. 선택(파란) 테두리는 키패드가 열린 동안에만 그린다.

읽기 전용일 때는 값만 보여 주고 아이콘과 키패드는 두지 않는다.

**크기**  
기본 최소 크기보다 작아지지 않는다. 수식을 입력하면 박스가 늘어나고, 지우면 내용에 맞게 줄어든다. 값을 모두 비우면 키패드를 닫지 않아도 기본 크기로 돌아간다.

---

## 입력 포커스와 키패드

입력창을 누르는 것과 키보드 아이콘을 누르는 것은 다르다.

- **입력창 클릭**: 입력창에 포커스가 가고, 디바이스 키보드로 바로 쓸 수 있다. 수식 키패드는 열리지 않는다.
- **키보드 아이콘**: 수식 키패드가 열린다. 다시 누르면 키패드만 닫히고, 입력 포커스는 유지된다.
- **바깥 클릭**: 입력 포커스와 키패드를 함께 닫는다.

닫힌 입력창에 숫자 등을 바로 쳐도 포커스만 열고, 키패드는 열지 않는다.

---

## 플로팅 키패드

키패드는 화면(뷰포트)에 고정한다. 위쪽 핸들로 위치를 옮길 수 있고, 화면 밖으로 나가지 않게 보정한다. 입력창이 늘거나 줄어도 키패드는 그 자리를 유지한다.

```
[ 수식 값                    ⌨️ ]
                 ┌ 핸들 ─────────┐
                 │ [서랍] │ 숫자패드 │
                 └────────────────┘
```

**우측 숫자 패드 (5×5)**  
숫자, 사칙, 분수, 루트, `x`/`y`, 커서, 지우기, 엔터를 둔다. 서랍을 열지 않아도 기본 대수·연산은 여기서 끝낸다.

**좌측 서랍**  
`>` / `<`로 열고 닫는 심화 기호 영역이다. 중등은 기본·대수·기하, 고등은 여기에 집합·행렬·통계를 더한다. 맨 앞 탭은 최근 사용한 심화 기호다.

| 레벨 | 서랍 탭 |
| --- | --- |
| 중등 | 최근 사용, 기본, 대수, 기하 |
| 고등 | 최근 사용, 기본, 대수, 기하, 집합·행렬, 통계 |

탭은 한 줄로 두고, 넘치면 가로로 스크롤한다. 심화 키는 4열 격자이며 세로만 스크롤한다. 행렬처럼 넓은 키는 한 행에 2개까지 둔다.

---

## 키패드로 입력하는 것과 디바이스 키보드

수식 키패드 버튼과 디바이스(물리/OS) 키보드는 같은 LaTeX로 들어간다. 어디에 포커스가 있어도, 수식 입력이 열린 동안 친 값은 키패드와 동일한 방식으로 처리한다.

- 숫자와 `.` `+` `-` `=` 는 그대로 넣는다.
- `*` 는 곱하기(`\times`), `/` 는 나누기(`\div`)로 넣는다.
- `x` `y` 는 변수로 넣는다.
- 백스페이스는 지우고, 좌우 화살표는 커서를 옮긴다.
- 엔터는 지금 입력창에 있는 LaTeX를 제출한다.

## 다음에 열었을 때 남는 것

브라우저를 닫았다가 다시 열어도 아래는 유지한다.

- 마지막으로 보던 서랍 탭
- 최근 사용한 심화 기호 (최대 12개). 우측 패드의 숫자·사칙·분수·루트·변수는 넣지 않는다.
- 서랍을 열어 두었는지
- 키패드를 옮겨 둔 위치

이력이 없으면 탭은 기본, 서랍은 닫힌 상태로 시작한다.
