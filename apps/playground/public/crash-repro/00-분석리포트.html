수업보드 렌더러 크래시
STATUS_STACK_OVERFLOW

교사·학생 수업보드를 한 시간 넘게 열어 두면 크롬 탭 전체가 오류 화면으로 바뀌는 문제의 원인을 재현으로 확정하고, 수정안 두 가지를 검증했습니다.

작성 2026-10-19 대상 프론트엔드 · rqti-viewer 담당 영향 교사웹 · 학생웹 공통 상태 원인 확정 · 수정안 검증 완료

서버 장애가 아닙니다. rqti-viewer 0.4.6이 수식을 다시 조판할 때마다 이전 결과 안에 새 결과를 겹쳐 넣어, DOM 깊이가 5초마다 두 겹씩 늘어나다 크롬 렌더러의 네이티브 스택을 넘깁니다.

신고된 증상

교사 계정으로 수업보드를 열고 1시간 이상 머물면, 페이지가 크롬 기본 오류 화면 앗, 이런! · STATUS_STACK_OVERFLOW로 바뀝니다. 같은 계정으로 띄워 둔 모든 탭이 동시에 같은 화면이 됩니다 — 같은 사이트의 탭들은 렌더러 프로세스를 공유하므로, 한 탭이 스택을 넘기면 전부 함께 죽습니다. 학생 계정에서도 동일하게 재현됩니다.

원인 체인

  1. 1

    10-16 배포에서 rqti-viewer를 0.4.2 → 0.4.6으로 올렸습니다.

    이 버전부터 수식을 MathJax로 그립니다. 교사웹·학생웹이 같은 뷰어를 쓰기 때문에 두 서비스에서 함께 나타납니다.

  2. 2

    뷰어가 수식마다 <MathJax dynamic>(better-react-mathjax 3.0.3)을 씁니다.

    MathJaxContext에 src를 지정하지 않아 기본값인 tex-mml-chtml.js가 CDN에서 로드됩니다. 이 번들은 MathML 입력 처리기를 포함합니다.

  3. 3

    dynamic 모드는 부모가 리렌더될 때마다 전체를 다시 조판합니다.

    의존성 배열이 없는 effect라 typesetClear() → typesetPromise()가 매번 실행됩니다. 수업보드는 presence 수신으로 5초마다 리렌더됩니다.

  4. 4

    재조판 때 MathJax가 자기 출력을 새 수식으로 다시 찾아냅니다.

    이전 출력에 접근성용으로 심어 둔 <mjx-assistive-mml> 안의 MathML을 입력으로 인식해, 기존 출력 안에 새 출력을 중첩시킵니다. typesetClear()로는 지워지지 않습니다.

  5. 5

    DOM 깊이가 선형으로 늘어나 Blink 레이아웃 재귀가 스택을 넘깁니다.

    5초마다 깊이 +2 → 1시간이면 약 1,500단. 레이아웃·스타일 계산은 노드마다 재귀 호출이라, 일정 깊이에서 네이티브 스택이 터지고 렌더러 프로세스가 종료됩니다.

수정안

MathJax 설정이 뷰어 내부에 하드코딩되어 있어 교사웹·학생웹에서는 덮어쓸 수 없습니다. rqti-viewer 패치가 필요합니다. 네 가지를 같은 조건에서 검증했고, 결과는 아래와 같습니다.

추가 권장 — 내용이 바뀌지 않는데도 5초마다 전체를 다시 조판하는 구조 자체가 불필요한 부하입니다. 뷰어는 이미 key 교체로 문항을 갈아끼우므로, dynamic을 끄고 마운트 시 1회만 조판해도 동작에 지장이 없습니다. 위 두 수정과 별개로 검토할 가치가 있습니다.

패치 전 임시 완화책은 0.4.2로 롤백뿐이며, 앱 레벨 우회는 없습니다.

원인이 아닌 것

같은 시간대 로그에서 함께 올라온 항목들입니다. 확인했고, 모두 크래시의 결과이거나 정상 동작입니다.

  • 제외 소켓 서버 — 해당 시간대 ERROR 로그 0건. 올라온 것은 WebSocketMessageBrokerStats 주기 통계이며, 로그 레벨도 INFO입니다. 문구에 포함된 "error"라는 단어에 검색이 걸린 것입니다.
  • 제외 presence stale 제거 · IdleRoomSweeper — 설계된 정리 동작입니다. 탭이 크래시로 사라지면 DISCONNECT 프레임 없이 끊기므로, 서버가 잔여 세션을 걷어낸 기록입니다. 원인이 아니라 결과입니다.
  • 제외 transport error 약 5% — 모바일 네트워크 전환·탭 종료·프록시 idle timeout으로 평상시에도 나오는 수준입니다. 크래시로 죽은 탭들이 여기에 더해집니다.
  • 제외 프론트엔드 앱 코드 — 교사·학생 양쪽의 소켓 재연결, 타이머, 캔버스 오버레이, ResizeObserver·MutationObserver, zustand 스토어를 모두 확인했습니다. cleanup이 모두 걸려 있고 DOM 깊이를 늘리는 경로가 없습니다.
